# src/chrome

ウィンドウの形式に依らないクローム部品。単一文書のガワ (`src/shell/`) と
プロジェクトウィンドウのガワ (`src/project/`) の両方から使う。

ここに置くものの条件:

- ウィンドウが 1 つ持てば足りるもの (トースト・ポップオーバー・検索バーなど)
- 「文書 1 つ」ではなく「ウィンドウ 1 つ」に属するもの
- 中身 (`src/viewer/`) を知っていてよいが、特定のガワの構造を知らないもの

マウント先の要素は呼び出し側が渡す。`document.querySelector` をこの中で
直接使わないこと (ガワによって markup が違うため)。
