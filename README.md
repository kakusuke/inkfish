# Inkfish 🦑

シンプルで軽量な Markdown ビューアー。エディタは付属していません。
お好きなものをお使いください。

```sh
inkfish doc.md        # ファイル 1 つ
inkfish docs/         # フォルダごと
```

メニューの「開く…」「フォルダを開く…」、ウィンドウへのドロップ、
Finder の「このアプリケーションで開く」でも開けます。

## できること

- ファイルを開く
  - GitHub Flavored Markdown を表示
  - Marp スライドを表示
  - Mermaid を表示
    - ELK レイアウト対応
  - YAML フロントマターをカードで表示
- フォルダを開く
  - ツリーとタブで表示
  - タブの切り離しと取り込み
  - git の変更を表示
    - 範囲を選んで比較
    - リモートから取り込む
    - 2 つの版を左右に並べて表示
- パスをコピー
  - git の差分は、コマンドラインに貼ると同じ差分が開く形式
- PDF で書き出す
- 外部エディタで開く
